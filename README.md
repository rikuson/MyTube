# CodexTube

見たい動画に集中するためのmacOS向けYouTube視聴アプリ。検索意図に合う動画と、登録チャンネルの動画だけを表示します。

現在は速度比較のため、YouTubeの検索結果を1ページ50件、取得順で表示します。AIによる評価・絞り込みは停止中です。検索にはyt-dlpが必要です。

## 使い方

### 動画を検索する

検索したいキーワードを入力して「動画を探す」を押します。結果と取得時間が表示されます。検索中はキャンセルできます。

検索結果は1ページ50件です。続きがある場合は「次の50件」、戻る場合は「前の50件」で移動できます。

### 動画を再生する

検索結果の「アプリ内で再生」を押すと、CodexTubeの再生ウィンドウが開きます。プレイヤーの再生ボタンを押して視聴してください。ウィンドウを閉じると検索結果に戻れます。

再生終了後に次の動画へ自動で進むことはありません。投稿者が埋め込み再生を許可していない動画などは再生できません。

### 登録チャンネルから見る（準備中）

1. YouTubeアカウントと連携し、登録チャンネルを同期します。
2. 登録チャンネルの動画一覧から動画を選んで再生します。
