# MyTube

見たい動画に集中するためのmacOS向けYouTube視聴アプリ。検索と登録チャンネルだけを表示します。

現在は速度比較のため、YouTubeの検索結果を1ページ50件、取得順で表示します。AIによる評価・絞り込みは停止中です。検索にはyt-dlpが必要です。

## 使い方

### 登録チャンネル（デフォルト表示）

起動時は登録チャンネルの最新動画が表示されます。macOSのChromeでYouTubeにログインしておいてください。

- ChromeにYouTubeへログイン済みのセッションが残っている必要があります。
- アプリ名を押すと、登録チャンネルの動画を更新します。
- サイドバーでチャンネルを選ぶと、そのチャンネルの動画を1ページ50件で表示します。
- 動画を押すと、現在のウィンドウで再生します。

### 動画を検索する

ヘッダーの検索欄にキーワードを入力して「検索」を押すと、検索結果に切り替わります。結果と取得時間が表示されます。検索中はキャンセルできます。

検索結果は1ページ50件です。続きがある場合は「次の50件」、戻る場合は「前の50件」で移動できます。

検索欄をクリア（×ボタン）すると、登録チャンネルの表示に戻ります。

### 動画を再生する

検索結果・登録チャンネルのどちらからでも動画を押すと、現在のウィンドウにプレイヤーが表示されます。「戻る」を押すと一覧に戻れます。

再生終了後に次の動画へ自動で進むことはありません。投稿者が埋め込み再生を許可していない動画などは再生できません。

## ビルドと起動

事前に次のソフトウェアをインストールしてください。

- Node.js 22.12以降
- Rust
- yt-dlp
- Google Chrome

ChromeでYouTubeへログインした状態にしてから、依存パッケージをインストールします。

```sh
npm install
```

開発版を起動する場合は、次のコマンドを実行します。

```sh
npm run tauri dev
```

配布用のmacOSアプリをビルドする場合は、次のコマンドを実行します。

```sh
npm run tauri build -- --bundles app
```

ビルドしたアプリは次の場所に生成されます。

```text
src-tauri/target/release/bundle/macos/MyTube.app
```

Finderから `MyTube.app` を開くか、ターミナルから起動します。

```sh
open src-tauri/target/release/bundle/macos/MyTube.app
```
