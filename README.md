# CodexTube

見たい動画に集中するためのmacOS向けYouTube視聴アプリ。検索意図に合う動画と、登録チャンネルの動画だけを表示します。

検索にはローカルのCodex CLIを使い、見たい内容や除外条件に合う動画を絞り込みます。自分で選んだ動画をアプリ内プレイヤーで視聴するために作っています。

現在開発中です。検索機能を利用できます。登録チャンネルの同期とアプリ内再生は準備中です。

検索には、ログイン済みのCodex CLIとyt-dlpが必要です。検索時にCodexの利用枠を消費します。

## 使い方

### 動画を検索する

1. 見たい内容や除外したい条件を入力します。例：「パン作りの初心者向け解説。ホームベーカリーを使う動画は除外」
2. 字幕などの内容を確認でき、条件に合う動画が、おすすめ度・マッチ度を重みづけした順に表示されます。内容を確認できない動画は表示されません。
3. 「並び順の調整」でマッチ度・おすすめ度の比率を変えられます。

検索は候補5件を対象に、日本語・英語の字幕で内容を確認します。該当する動画がない場合は空の結果になります。検索中はキャンセルできます。

### 登録チャンネルから見る（準備中）

1. YouTubeアカウントと連携し、登録チャンネルを同期します。
2. 登録チャンネルの動画一覧から動画を選んで再生します。
