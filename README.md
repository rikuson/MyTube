# MyTube

見たい動画に集中するためのmacOS向けYouTube視聴アプリ。検索と登録チャンネルだけを表示します。

現在は速度比較のため、YouTubeの検索結果を1ページ50件、取得順で表示します。AIによる評価・絞り込みは停止中です。検索にはyt-dlpが必要です。

## 使い方

### 登録チャンネル（デフォルト表示）

起動時は登録チャンネルの最新動画が表示されます。macOSのChromeに保存されているYouTubeのログイン情報をMyTubeが直接読みに行くため、YouTubeアカウントの連携操作は不要です。

- ChromeにYouTubeへログイン済みのセッションが残っている必要があります。
- ヘッダーの「更新」を押すと、MyTubeが yt-dlp 経由で `https://www.youtube.com/feed/subscriptions` を取得し、登録チャンネルの最新動画順に表示します。
- 「アプリ内で再生」を押すと、再生ウィンドウで視聴できます。再生できるのは現在の同期結果に表示されている動画だけです。

### 動画を検索する

ヘッダーの検索欄にキーワードを入力して「検索」を押すと、検索結果に切り替わります。結果と取得時間が表示されます。検索中はキャンセルできます。

検索結果は1ページ50件です。続きがある場合は「次の50件」、戻る場合は「前の50件」で移動できます。

検索欄をクリア（×ボタン）すると、登録チャンネルの表示に戻ります。

### 動画を再生する

検索結果・登録チャンネルのどちらからでも「アプリ内で再生」を押すと、MyTubeの再生ウィンドウが開きます。プレイヤーの再生ボタンを押して視聴してください。ウィンドウを閉じると元の一覧に戻れます。

再生終了後に次の動画へ自動で進むことはありません。投稿者が埋め込み再生を許可していない動画などは再生できません。
